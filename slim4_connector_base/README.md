# Slim4 Connector Base

Configures the Slim4 interfaces and the mapping between Odoo fields and Slim4 fields, and adds the product and supplier
fields Slim4 needs (Slim4 warehouses, primary supplier, IOQ). The other Slim4 modules use this configuration to exchange
data with Slim4.

The full functional documentation of the connector is in
[static/description/index.html](static/description/index.html), shown on the module page in Odoo Apps.
